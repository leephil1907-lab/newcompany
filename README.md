# AgroBridge Consult

Agricultural consultancy platform for farmers, agribusinesses, investors, cooperatives and institutions.

## Brand
- Tagline: Connecting Farmers to Smarter Growth.
- Domain: agrobridgeconsult.com
- Primary green: #1B5E20
- Leaf green: #4CAF50
- Earth brown: #6D4C41
- Background: #F7F8F5

## Stack
- Next.js App Router
- React and TypeScript
- Tailwind CSS v4
- Framer Motion (planned for page and interaction motion)
- Lucide icons

## Local development
```bash
npm install
npm run dev
```

## Current implementation
- Responsive site header and footer
- Home page
- Company profile page
- Services catalogue with 12 service categories
- Dynamic service detail pages
- Contact page with email-based enquiry handoff
- SEO metadata and design tokens

## Planned phases
1. Complete public website and brand system
2. PostgreSQL database, authentication, client portal, admin dashboard, consultation workflow and transactional email
3. Agricultural AI assistants and case management
4. Academy and marketplace
5. Investment advisory and advanced workspace
6. Production hardening and deployment

## Production configuration
No database, email provider, WhatsApp provider, payment provider, weather data source or AI provider is configured yet. Add credentials through environment variables and server-side integrations during the relevant implementation phase. Do not commit secrets.
